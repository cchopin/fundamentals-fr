Ensuite, on s'exerce à faire des requêtes HTTP avec l'un des outils de ligne de commande les plus courants pour HTTP : `curl`.
Contrairement à netcat, curl est conçu pour HTTP : il n'est pas nécessaire d'écrire la requête brute.
Il faut plutôt connaître les bonnes options du programme pour obtenir ce que l'on veut.
Ici, il suffit de faire une requête GET vers le bon endpoint !
