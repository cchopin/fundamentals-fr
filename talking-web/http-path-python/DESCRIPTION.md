Dernier outil de la boîte à outils HTTP : la bibliothèque [requests](https://requests.readthedocs.io/en/latest/) de Python.
Avec le navigateur, ce sera probablement l'outil le plus utilisé pour HTTP.
Requests permet de scripter des interactions web complexes, ce qui sera nécessaire pour certaines attaques plus tard.
Pour l'instant, c'est simple : ouvrir Python, `import requests`, et faire une requête GET pour obtenir le flag !
