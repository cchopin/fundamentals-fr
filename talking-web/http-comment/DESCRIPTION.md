HTTP est le _HyperText_ Transfer Protocol, c'est-à-dire le protocole de transfert d'hypertexte.
L'hypertexte, nommé à l'époque de l'optimisme technologique de la fin du XXe siècle, est un texte qui porte, en plus de son contenu, des données sur la manière dont il doit être interprété.
Aujourd'hui, cela passe par différents moyens : HTTP sert à transporter de nombreux types de ressources, et le navigateur les combine pour construire les sites web que l'on voit et avec lesquels on interagit.
Le plus ancien de ces types est le langage HTML (HyperText Markup Language).

HTML décrit, de façon que le navigateur puisse l'interpréter, les éléments qui doivent apparaître (au départ) sur une page web.
Les subtilités du HTML seront abordées dans les modules suivants. Ici, on s'exerce à percer le voile du site pour regarder le HTML qui se cache derrière.
Comme précédemment, il faut trouver le point de terminaison (endpoint) et y accéder dans le navigateur intégré au dojo.
Mais le HTML envoyé _cache_ le flag.
Il faut trouver comment afficher le code source de la page, et non le résultat rendu, pour accéder à cette donnée cachée.
