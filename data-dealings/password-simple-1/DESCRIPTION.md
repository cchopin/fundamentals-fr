Dans la plupart des analyses de cybersécurité, on analyse des logiciels qu'on n'a pas écrits soi-même, comme ce programme.
La toute première compétence de ce module est donc de lire un logiciel pour comprendre les données qu'il attend.
On commence par ce programme Python trivial.

Le programme se trouve dans `/challenge/runme` : il demande un mot de passe délicat avant de révéler le flag.
C'est le programme le plus simple que l'on lira dans ce parcours : il lit des données sur l'entrée standard et fait une seule vérification simple.

Il faut lire le programme, comprendre le code Python, et faire en sorte que le programme donne le flag !
