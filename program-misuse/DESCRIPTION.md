Pour chaque défi de ce module, un programme standard différent, dont `root` est propriétaire, a son bit `suid` activé. Ce programme n'a pas été conçu pour être exécuté avec des privilèges élevés.

Le but est de détourner le programme pour lire le flag. Certains de ces outils savent déjà lire des fichiers directement. Beaucoup ne le savent pas, et c'est justement l'intérêt de l'exercice.

Pour comprendre comment utiliser ces programmes, et comment les détourner, il faut prendre le temps de lire leurs pages `man`.
