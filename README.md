# Fundamentals (français)

Traduction française, à usage privé, du dojo **Fundamentals** de [pwn.college](https://pwn.college).

Ce dépôt ne contient ni le code des défis, ni leurs vérifications : les défis sont importés du dojo officiel `fundamentals`, avec les mêmes environnements et les mêmes flags. Seuls les textes sont traduits : noms et descriptions des modules et des défis.

## Contenu

- `dojo.yml` : déclaration du dojo, de ses quatre modules, importés du dojo officiel.
- Un dossier par module (`data-dealings`, `talking-web`, `program-misuse`, `sql-playground`) avec `module.yml`, `DESCRIPTION.md` et un dossier par défi.
- `GLOSSAIRE.md` : termes techniques retenus.

## Installation sur pwn.college

Même procédure que pour les autres dojos traduits : créer le dojo à partir de `cchopin/fundamentals-fr` sur pwn.college, ajouter la clé de déploiement affichée par le formulaire en lecture seule sur le dépôt, puis valider. Le dojo est déclaré `type: hidden`.

Les liens internes pointent vers `https://pwn.college/fundamentals-fr/…` ; ils ne fonctionnent qu'après l'installation.
