Des fonctions comme `substr` ne servent pas seulement à filtrer : on peut aussi `SELECT` des expressions de ce type (à la place des colonnes habituelles, ou en plus d'elles) !
C'est très pratique quand on ne veut pas (ou, dans le cas de ce défi, qu'on ne peut pas) récupérer _toutes_ les données, mais seulement le résultat d'un calcul sur ces données.
Dans ce défi, le système ne laisse pas lire le flag en entier.
Peut-on le lire morceau par morceau ?
