*Introduction ajoutée pour cette traduction, hors traduction directe.*

Dans ce module, on interroge une base de données avec SQL, le langage standard des bases relationnelles.
Les défis utilisent SQLite, un moteur léger qui stocke les données dans un simple fichier.

On commence par la requête la plus simple, `SELECT`, qui sert à lire les données d'une table.
Les défis suivants ajoutent la clause `WHERE` pour filtrer les lignes, puis `LIMIT` pour n'en garder qu'une partie, et `substr` pour extraire une partie d'une valeur.
Un défi apprend aussi à interroger les métadonnées de la base, pour découvrir les tables qu'elle contient sans les connaître à l'avance.

Chaque défi s'appuie sur le précédent : il faut lire le code de la base, comprendre comment les données sont organisées, puis écrire la requête qui fait apparaître ce que l'on cherche.
